# Weenoko downloads

Windows installers and update information for Weenoko.

[Download Weenoko for Windows](https://weenoko.com/download/windows)

Weenoko is a local desktop application. The source repository is maintained separately and is not published here. No account is required to download the app.

## Install and update

The download link saves the latest Windows x64 installer directly. Open the downloaded Weenoko setup file and follow the installer. Existing Weenoko chats and settings remain in the application data directory when installing a newer version.

The other release files support automatic updates and integrity checks. You only need the `.exe` installer. GitHub's automatic “Source code” ZIP and tarball contain this downloads repository's README, not the private application source.

Updater-enabled versions check and download updates in the background. **Restart to update** appears in the sidebar when a verified update is ready. Click the installed version to check manually, see download progress or retry a failed download. Restart when your work is finished; active agent tasks and background operations must finish first. Saved chats, settings and durably waiting approvals remain available after restarting.

Version 1.0.0 predates the updater and requires one manual installation of a newer version.

The Windows installers are unsigned. Windows may display an unknown-publisher message. Update downloads use HTTPS and file-integrity checks; this is separate from Windows publisher certification.

Release notes describe each version. Installers and metadata for a published version are not replaced; fixes receive a new version number.
